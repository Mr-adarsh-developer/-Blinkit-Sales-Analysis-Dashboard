# 📊 Blinkit Sales Analysis Dashboard


An interactive **Sales Analysis Dashboard** built using **Microsoft Excel** and **Power BI** to analyze retail sales performance, outlet distribution, customer ratings, and product category trends.

---

## 🚀 Project Overview

This project demonstrates an end-to-end **Data Analytics & Business Intelligence workflow**:

* **Data Cleaning & Preparation** using Excel
* **Data Modeling** in Power BI
* **DAX Calculations & KPI Creation**
* **Interactive Dashboard Development**
* **Business Insight Generation**

The dashboard helps stakeholders monitor sales performance and identify trends across outlets, item categories, and outlet sizes.

---

## 📈 Dashboard Features

* 💰 **Total Sales Analysis**
* 🛒 **Number of Items Sold**
* ⭐ **Average Customer Rating**
* 📊 **Average Sales per Item**
* 🏬 **Sales by Outlet Type**
* 📍 **Sales by Outlet Location**
* 📦 **Sales by Outlet Size**
* 🥫 **Item Type Performance Analysis**
* 📅 **Outlet Establishment Trend**
* 🎛️ **Interactive Filters and Slicers**

---

## 📌 Key Insights

* Medium-sized outlets contributed the **highest share of total sales**.
* Certain item categories generated **significantly higher revenue** than others.
* Outlet expansion years showed **noticeable sales growth trends**.
* Interactive filtering enables **quick performance comparison** across outlets and product categories.
